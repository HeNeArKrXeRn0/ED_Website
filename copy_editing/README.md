# Espace de Révision et d'Édition des Textes (Copywriting)

Bienvenue dans votre dossier dédié à la révision de l'ensemble des textes du site **Equip Drones**.

---

## 🎯 Comment utiliser ces fichiers ?

1. **Aucun code HTML à manipuler** : Chaque fichier Markdown représente une page ou un composant clé du site.
2. **Localisation claire** : Chaque section indique son emplacement visuel dans la page (ex: Hero, Chiffres clés, Cartes de services, etc.).
3. **Texte complet pré-rempli** : Le texte actuel du site y est intégralement reporté.
4. **Modifiez directement dans les fichiers** :
   - Vous pouvez réécrire directement les phrases sous les champs correspondants.
   - Vous pouvez également ajouter des commentaires, des consignes ou des variantes si vous hésitez.
5. **Quand vous êtes prêt** : Il vous suffira de me dire : *"J'ai terminé la révision, mets à jour le site avec les nouveaux textes"* et je synchroniserai automatiquement tout le site web (fichiers HTML et fichiers de données JS) sans casser le design ni le code.
