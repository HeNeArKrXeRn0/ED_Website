## 1. How to read this document

This is a read-only inventory of the catalogue as it exists at runtime. It was generated by
evaluating `assets/js/data.js` locally, not by reading documentation, so it reflects the code
rather than the plan.

Each record exposes exactly these fields:

```text
id, name, segment, category, type, tagline, usage, useCases,
highlights, specs, availability, image, imageFallback, djiUrl, compatiblePayloads
```

Two consequences worth stating up front:

- **There is no `serviceLevel` field.** The "Support type" column below is *derived* from
  `segment`, not read from a field. See §4.
- **There are no `accessory` or `spare_part` records.** `type` only ever takes the values
  `aircraft` and `payload`. See §5.

## 4. Status reference

`availability` accepts five values. The French strings are the ones visitors actually see, from the
`avail.*` keys in `assets/js/i18n.js`.

| Value | Visitor label (FR) | Visitor label (EN) | Quote button | Records |
|---|---|---|---|---|
| `coming_soon` | Bientôt disponible | Coming soon | Enabled | 26 |
| `discontinued` | Fin de série | Discontinued | Disabled | 10 |
| `not_available` | Non disponible | Not available | Disabled | 2 |
| `in_stock` | En stock | In stock | Enabled | 0 |
| `on_order` | Sur commande — 4 à 6 semaines | On order — 4 to 6 weeks | Enabled | 0 |

`assets/js/app.js` gates the RFQ cart on `QUOTE_ALLOWED = ['in_stock', 'on_order', 'coming_soon']`,
so `discontinued` and `not_available` products cannot be added to a quote.
